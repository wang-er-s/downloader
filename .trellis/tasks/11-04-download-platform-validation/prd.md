# 四平台集成与交付验收

## Goal

用可复查的平台运行与故障证据确认完整下载管理器满足需求，而不是只证明文档齐全或单元测试通过。

## Background

依赖前六个实施子任务。验收权威为[需求文档](../../../.agents/specs/download-manager/requirements.md)全部 49 项（1.1–1.6、2.1–2.5、3.1–3.5、4.1–4.5、5.1–5.6、6.1–6.8、7.1–7.4、8.1–8.5、9.1–9.5）及[设计](../../../.agents/specs/download-manager/design.md)的故障注入与平台矩阵。

## Requirements

- Android/macOS/Windows 构建和实际核心流程可交付；iOS 有真实可行性和系统行为结论。
- 进程生命周期、恢复、文件发布和权限错误在实际平台验证。
- 五项独立审查修订有对应实现与证据；环境缺失不是测试通过。
- 记录测试环境、命令、产物与结果；不把本地 debug 签名当分发签名。

## Out of Scope

商店发布、上传产物、自动提交/推送、未经授权申请权限/证书或调整功能范围。

## Acceptance Criteria

- [ ] 49 项验收逐项记录测试、平台、证据位置及 pass/failed/unverified，不以引用表替代测试。
- [ ] Android/macOS/Windows release 包实际构建运行；必要原生资产存在，签名/分发状态准确说明。
- [ ] Android API 29/30/33/35/36 的后台/终止/重启/权限；macOS sandbox 与退出；Windows 路径/锁定/DLL 交付均有结果。
- [ ] iOS 实体设备覆盖挂起、系统终止、强退、恢复和私有 resume data 安全；不可满足时报告证据供用户决定，不静默删平台。
- [ ] 回执三处交付中断、未知总长、目标创建/最终操作后中断、旧执行身份、桌面拒绝静默重下均按设计验证。
- [ ] 中文交互、大字体/键盘/窗口、主题、缓存、打开/清理和默认/自选目录端到端通过。
- [ ] 没有未解决的误删/覆盖/丢回执/自动重提阻断；未测项清晰保留，任务不伪报完成。
