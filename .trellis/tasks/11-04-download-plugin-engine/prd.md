# iOS 与桌面下载引擎安全补丁

## Goal

让 iOS/macOS/Windows 的下载执行满足停止、恢复和持久回执规则，保留现有引擎复用而不静默破坏部分文件。

## Background

父任务见[任务总览](../11-04-download-manager/prd.md)。源[需求](../../../.agents/specs/download-manager/requirements.md) 1.1、1.3–1.4、2.1–2.2、3.1–3.4、8.1–8.2、8.5；[设计](../../../.agents/specs/download-manager/design.md)已确认 9.5.9 原版有丢回执、失败清材料、未知总长无字节事件和桌面静默重下路径。本任务依赖 contracts-store。

## Requirements

- 暂停须实际停止并保存材料和回执；普通暂停/失败确认不丢可恢复材料。
- 进程中断后的执行回执可重放，业务确认前不破坏性删除；重复确认不得删除较新材料。
- 未知总长仍能观察真实已下载字节；速度和剩余时间不伪造。
- 实际续传响应不安全时保留原部分数据，等待从零下载确认。
- 桌面终止后不自动下载；iOS 只关联系统既有任务，不重提失败/取消项；系统后台完成文件及时持久保护。

## Out of Scope

Android 执行、重写三平台 HTTP 引擎、用户目标目录发布、业务页面及未经同意降低 iOS 需求。

## Acceptance Criteria

- [ ] 固定发布归档、校验来源、许可证及最小补丁差异可查；不直接交付原版并声称满足安全契约。
- [ ] PluginEngine 满足共享 Engine 接口；非破坏性 inspect、持久接收/确认及显式材料释放有实际实现。
- [ ] 交付中断三处故障注入均能重放，AppStore 未提交时不能确认，零重试失败仍保留恢复材料。
- [ ] 无 Content-Length 的慢响应完成前有递增字节；未知总长、比例、剩余时间保持未知。
- [ ] 桌面恢复遇 HTTP 200/坏 Range/变更验证器/本地材料损坏时，原文件长度和散列不变，确认前无从零请求。
- [ ] 桌面退出/强杀后重开不自动传输；iOS 挂起、系统终止、强退分别有真实证据，不把缺设备标通过。
- [ ] iOS 无法满足安全续传门槛时给出具体证据并保持未验收，由用户决定范围，不擅自降级。
