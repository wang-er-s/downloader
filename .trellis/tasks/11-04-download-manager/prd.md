# 实现跨平台下载管理器

## Goal

交付 Android、macOS、Windows 可实际使用的 HTTP/HTTPS 下载管理器，并按可行性验证争取同步提供 iOS。用户能管理下载与完成文件、保存复用配置、选择目录和主题；异常与进程终止不得造成静默重下、覆盖文件或丢失任务。

## Background

- 功能权威为[需求文档](../../../.agents/specs/download-manager/requirements.md)，共 9 组、49 项验收标准。技术权威为[审查修订后的设计](../../../.agents/specs/download-manager/design.md)及[架构规范](../../spec/frontend/architecture.md)。
- 现有仓库仍为 Flutter 计数器，四平台工程存在，但没有下载业务依赖与实现。Flutter 3.44.8 / Dart 3.12.2 已核对。
- 用户已同意创建任务并准备实现。本父任务协调子任务、保留需求映射及收集集成证据；子任务规划摘要确认后才激活，不以父任务直接替代实施边界。

## Requirements

| 来源验收项 | 用户可观察结果 | 主要归属 |
| --- | --- | --- |
| 1.1–1.6 | 有效链接可下载，显示真实进度和分类；拒绝无效/超范围协议 | 引擎、仓库、界面 |
| 2.1–2.5 | 暂停真正停止；安全续传或确认重下；取消/删除按选择执行 | 引擎、文件、仓库、界面 |
| 3.1–3.5 | 平台允许时后台执行，持久恢复且符合各平台手动/系统恢复规则 | 持久化、引擎、仓库、集成 |
| 4.1–4.5 | 系统打开与 Android APK 交接；重下保留原文件；无分享 | 文件、仓库、界面 |
| 5.1–5.6 | 配置可新增编辑复用，保存不启动，删除不级联任务 | 仓库、界面 |
| 6.1–6.8 | 固化目录优先级、默认位置、名称推导、重名不覆盖和存储错误反馈 | 引擎、文件、仓库、界面 |
| 7.1–7.4 | 主题/目录偏好持久化，授权可处理，无代理配置 | 持久化、文件、仓库、界面 |
| 8.1–8.5 | 错误可识别、可手动重试、不误标完成或静默破坏部分文件 | 所有实施子任务 |
| 9.1–9.5 | 中文、空态、长文本、键盘/窗口/大字体及无障碍可用 | 界面、集成 |

## Platform and Safety Constraints

- Android/macOS/Windows 必需；iOS 为验证可行性后争取同步提供的平台，不能擅自删减功能。
- Android/桌面进程终止后只恢复记录、等待用户继续；iOS 仅关联已提交的系统后台任务，不重提失败/取消任务；用户强制退出按系统取消处理。
- 原版 background_downloader 9.5.9 的已知缺口必须在有限补丁和适配层解决，不能仅凭初始化参数声称安全。
- 回执、恢复材料及发布操作可追踪；未知总长仍有真实字节进度；未确认从零重下时不得破坏原部分文件；归属不明不猜测删除或重复发布。
- 候选支持基线沿用设计：Android API 29+、iOS 14+、macOS 10.15+、Windows 10/11 64 位。实际依赖/构建不符时先报告，不静默提高最低版本。

## Out of Scope

认证下载、磁链、视频解析、代理、分享、搜索、排序切换、批量管理、非中文语言、托盘、开机自启、守护进程、跨设备同步和额外通用任务框架。

## Acceptance Criteria

- [ ] 49 项源验收标准逐项关联到子任务及真实测试证据，不以文档引用覆盖代替功能通过。
- [ ] 五项独立审查问题有实现和验证：持久回执/材料、未知总长字节、发布中断恢复、执行身份、桌面安全续传。
- [ ] Android/macOS/Windows 的构建、下载控制、默认/自选目录、恢复与系统打开通过平台验收；iOS 提供通过证据，或保留明确限制交用户决定。
- [ ] 取消、删除、回执交付及文件发布的故障注入不造成误删、覆盖、重复副作用或自动恢复传输。
- [ ] 代码分析、相关 Dart/原生测试和实际 release 构建有可复查结果；缺设备/签名/Windows 环境时记录未验证，不标作通过。
- [ ] 不覆盖当前已有的无关修改，不自动提交或推送用户工作。
