# 下载仓库与恢复协调

## Goal

提供唯一、可恢复的任务及配置/设置业务状态，让界面操作与真实执行和文件结果一致。

## Background

依赖 contracts-store、plugin-engine、android-engine、file-storage 的安全原型。覆盖[需求](../../../.agents/specs/download-manager/requirements.md) 1.1、1.5、2.1–2.5、3.2–3.4、4.3–4.4、5.1–5.6、6.1–6.4、7.1–7.4、8.1–8.5；遵守[设计](../../../.agents/specs/download-manager/design.md)的输入/命令、回执确认、恢复与状态机。

## Requirements

- 任务列表、分类和数量有唯一不可变来源；初始读取失败不作为空列表。
- 创建幂等、目录固化、同任务操作串行；暂停/取消等待真实结果，重下必须确认。
- 用户取消/删除意图优先于迟到完成事件，重复/旧回执不得复活或重复发布任务。
- 平台恢复规则、确认重放和本地发布恢复严格分离，不将恢复记录等同重新传输。
- 缓存配置独立保存/编辑/删除，发起时创建新任务；主题和默认目录持久化并正确应用。

## Out of Scope

界面、引擎内部网络和原生发布实现、跨设备同步、通用调度框架。

## Acceptance Criteria

- [ ] create 同 requestId 相同输入幂等、不同输入拒绝；命令稳定记录且不在重试时改绑身份。
- [ ] watchTasks 先给一致快照；分类/数量派生，旧事件去重；初始错误可见。
- [ ] 回执与业务状态同事务保存后才确认；中断重放无重复副作用，失败材料不因普通确认消失。
- [ ] Android/桌面启动无自动下载；iOS 关联已有系统任务、不重提失败/取消项；不明发布结果不重复创建。
- [ ] 暂停/取消/删除与保存失败保持真实状态，确认/清理可重试，不伪报全面成功。
- [ ] 配置保存不下载、删除不级联；空配置目录发起时取最新默认值，已创建任务目录不变；重下保留原完成文件。
- [ ] 主题、目录设置、错误映射和事件去重有单元/存储集成及真实适配 smoke 证据。
