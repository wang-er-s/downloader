# 下载管理器 Flutter 界面

## Goal

用户在移动端和桌面端能够用中文完成下载、文件管理、缓存配置及设置，并理解真实执行结果与平台限制。

## Background

依赖 repositories，且真实引擎/文件安全门槛已通过。完整[需求](../../../.agents/specs/download-manager/requirements.md)的所有用户操作和反馈均需呈现，重点 1.1–1.6、2.1–2.5、4.1–4.5、5.1–5.6、7.1–7.4、9.1–9.5；以[截图评审](../../../.agents/specs/download-manager/review.md)和[设计](../../../.agents/specs/download-manager/design.md)为布局/交互基线。

## Requirements

- 下载/设置两个入口，下载中/已完成/缓存三类及真实数量；未发布项不归完成。
- 新建下载、缓存新增/编辑及发起、暂停/继续/取消/重下/打开/删除均可操作。
- 未知总长真实字节展示，百分比和剩余时间不虚构；等待操作不提前伪造最终状态。
- 清理、发布不明、权限、系统限制及错误有可理解反馈和适当确认。
- 主题、目录、空态、长内容、大字体、软键盘、窄窗口和无障碍均可用。

## Out of Scope

搜索、排序、批量、代理、分享、其他语言、托盘/守护功能及为视觉重构业务架构。

## Acceptance Criteria

- [ ] 七张截图对应的核心页面/弹窗均有实现；不凭截图新增已排除功能。
- [ ] 所有状态和数量订阅 Repository，不复制第二套任务集合，不直接访问 SQL/插件。
- [ ] 暂停/保存/删除反馈与真实结果一致，重下和删除文件均需明确选择，删除默认仅记录。
- [ ] 配置保存不下载；编辑取消保留；默认目录和主题持久后重开一致。
- [ ] 未知总长显示真实累计字节与未知值；发布 uncertain/清理失败不误报完成或消失。
- [ ] 中文、键盘、屏幕阅读器、大字体、长名称、空态、窄桌面窗口及弹窗避让有 Widget 与视觉/实际交互证据。
- [ ] 页面销毁不停止活动下载，正常桌面关闭/退出依约确认停止并保存；真实平台端到端流程可运行。
