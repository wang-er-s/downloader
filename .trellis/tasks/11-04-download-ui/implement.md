# Flutter 界面实施计划

## 依赖与准备

repositories 已验收且安全原型通过后激活。先逐张读取 docs/ 七张参考图，加载适用的 Flutter/UI 规范和 UI 设计技能；已有资料决定布局，不用新风格扩展范围。

- [ ] 读取 lib/main.dart、Widget 测试及实际仓库接口，确认所有入口和导出。
- [ ] 组装 app、Riverpod 和主题，替换计数器页面及相应旧 smoke test。
- [ ] 实现下载分类/列表、进度、空态和任务操作及确认反馈。
- [ ] 实现新建下载、缓存新增/编辑/发起和设置/目录选择，沿用共享校验。
- [ ] 接入真实错误/处理中与恢复提示；处理宽窄窗口、大字体、键盘、语义及桌面退出。
- [ ] Widget 测试后进行真实跨平台 smoke 和视觉/交互检查。

## 检查

flutter analyze、flutter test。Widget 覆盖真实状态订阅、分类数量、表单取消/校验、重下与删除选择、读取失败、未知总长及 publicationUncertain；Provider 测页面释放不会取消引擎。

按七张截图核对核心内容和交互。大字体、长链接、窄桌面、软键盘、焦点/屏幕阅读器及主题切换分别验证；真实 Engine 完成创建→暂停→继续→保存→打开/删除流程，缓存与目录设置重开一致。

## 停点与回滚

fake 数据仅用于隔离 Widget 测试，不冒充可运行业务。依赖或平台安全问题不能由 UI 藏错/伪造状态；仅回退本任务的界面变更，不清除存储和文件。
